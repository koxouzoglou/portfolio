# Konstantinos Oxouzoglou — Portfolio

Bilingual engineering portfolio focused on embedded systems, robotics,
artificial intelligence and software development.

## Live site

The portfolio is deployed through GitHub Pages:

<https://koxouzoglou.github.io/portfolio/>

## Highlights

- English and Greek content
- BIOS Beep Code Analyzer thesis case study
- Embedded AI, machine learning and full-stack projects
- Responsive dark interface
- Printable English and Greek CV
- Accessible navigation and reduced-motion support

## Stack

- Next.js
- React
- TypeScript
- CSS
- Lucide icons

## Local development

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Quality checks

```bash
npm run lint
npm run build
```
